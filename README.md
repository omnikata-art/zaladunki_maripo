# Zaladunki Maripo

Prosta aplikacja webowa do zarzadzania transportem:

- lista samochodow z numerami rejestracyjnymi,
- ladunki przypisane do konkretnych samochodow,
- kalendarz miesieczny zaladunkow,
- zapis danych w `localStorage`,
- eksport ladunkow do pliku `.ics`.

## Uruchomienie

Otworz `index.html` w przegladarce albo uruchom lokalny serwer:

```bash
python3 -m http.server 8765
```

Nastepnie wejdz na:

```text
http://127.0.0.1:8765/
```
